# Unity project instructions

- Read ProjectSettings/ProjectVersion.txt and Packages/manifest.json first.
- Use the existing Unity version, render pipeline, and input system.
- Preserve existing .meta files and asset GUIDs.
- Move or rename assets together with their .meta files.
- Do not edit generated folders such as Library, Temp, Logs, or Obj.
- Prefer Unity Editor APIs for scene and prefab changes.
- Keep changes small and use existing project patterns.
- Check compilation and run relevant tests when available.
- State any Unity Inspector setup or manual testing still required.
